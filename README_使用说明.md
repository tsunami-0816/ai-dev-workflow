# 从 0 到 1 项目自动工作流 · 使用说明

> 主控 [`WORKFLOW_工作流主控.md`](WORKFLOW_工作流主控.md) 是 <100 行的入口指针；四个域的唯一权威分别是 `WORKFLOW_步骤定义.md`（步骤）、`WORKFLOW_规则库.md`（规则 R1–R25）、`WORKFLOW_卡点协议.md`（卡点 / 闸门）、`WORKFLOW_执行约定.md`（单步协议 / 回流 / 看板）。本文件只讲「怎么用」，不复述流程细节；冲突时以专项文件为准。

---

## 一、这是什么

把一份模糊的项目描述，按固定步骤推进成可交付、可验收、可复盘的完整系统。步骤之间用落盘文档串联；AI 不能代替你判断的环节设为**人工卡点**，会停下来等你。

- **设计模块（可选）**：从 JD 选题 → 选题矩阵 → 一页纸设计书 → 存入预备仓库 `projects/_队列/`
- **生产模块**：`_队列/` 取设计书 → 基线 → 架构 → 开发 → 冒烟 → 契约 → 联调 → 重置 → 测试 → 安全 → 验收 → 交付 → 复盘 → 工作流自迭代

---

## 二、怎么用（三句话）

1. **选题**：说「按 JD 选题」，我产出选题矩阵（卡点1：你拍板方向）和设计书（机器闸门校验技术栈/工作量/技能点覆盖率，全绿自动入队，报红才叫你）。
2. **开工**：说「开工：<项目名>」从预备仓库启动，或「启动新项目：<项目名>，<描述>」直接开工。
3. **推进**：说「继续」；贴报错就说「这是报错：<粘贴>」；确认通过就说「人工检查通过，继续」。

---

## 三、需要你亲自确认的卡点

| 卡点 | 你要做什么 |
|---|---|
| step00 卡点1 | 选方向（选题矩阵里挑项目）；设计书由机器闸门校验，不再人工确认 |
| 第 1 步（三项输入） | 选项目类型（R25）、设计模式（R24 普通/精修）、是否录 demo 视频；指标量化由机器闸门判 |
| 第 3 步 架构评审 | 看技术选型能否落地、每个量化指标是否有机制支撑 |
| 第 6 步 冒烟 | 走一遍核心主流程，把真实报错完整贴回来 |
| 第 6.5 步 契约校验 | Agent 跑脚本并落盘，你复核「0 臆造接口」结论 |
| 第 8.5 步 安全扫描 | Agent 跑密钥/CVE/配置扫描，你做人工渗透并确认 P0/P1 清零 |
| 第 9 步 验收 | 先不看清单自由操作 10 分钟，再对照清单逐条走查 |
| 第 11 步 自迭代 | 确认采纳项后，我才真正改工作流文件 |

## 四、进度与产物

每个项目的 `_项目状态.md` 是**唯一进度看板**；每步产物落盘到对应编号目录，不靠对话记忆。跨对话只要说「继续」，我会先读看板恢复现场，不重做已完成步骤。

**换对话节点（5 处：5→6、6→7、7.5→8、8→9、9→10）**：到点我会**停下来**，给你一张交接卡和一句可直接粘贴的「继续 `<项目名>`，当前在 step X」，然后本条消息结束；我不会在同一对话里自己换上下文继续往下跑。若我越界了，你直接说「换对话」即可强制中断。

第 6~9 步发现的问题**只在项目根目录 `_问题台账.md` 记一次**（`open`→`fixed`→`verified`），不再分别建联调问题清单 / BUGLIST / 回归报告；台账里还有 open 或 fixed 的 P0/P1 时，门禁会把放行卡住。

## 五、常用命令

```bash
wf init <项目名> --desc "描述"      # 从模板建项目骨架
wf next <项目名>                    # 当前步骤 + 对应提示词模板
wf list                             # 所有项目与当前阶段
wf steps                            # 列出 steps.yaml 登记的步骤（--check 校验一致性）

# 队列事实列（状态/完成日期/当前卡点）：从看板+门禁推导，禁止手改
wf queue --sync                     # 回写队列事实列
wf queue --check --allow-missing    # 校验队列是否与看板/门禁一致（CI 用；本地可去掉 --allow-missing）

# 完成门禁（改队列状态为"已完成"前必须全绿）
python scripts/workflow_completion_check.py projects/<项目名>

# 工作流自身自检（CI 也跑；含「故意破坏文档、校验器必须报红」的负向用例）
python -m pytest scripts/tests -q
```
