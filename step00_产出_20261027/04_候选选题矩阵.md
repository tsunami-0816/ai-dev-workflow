# 候选选题矩阵（29 份 JD 驱动）

> 硬件约束：RTX 2050 4GB + 16GB 内存，禁止本地大模型微调/K8s/超 5 服务 Docker Compose。

## 三个候选项目

### A. 智能外呼语音对话平台

**一句话定位**：基于 FreeSWITCH + LLM 的 AI 外呼机器人平台，支持可视化对话流程图编排。

**业务场景**：企业批量外呼通知/回访/营销，运营人员通过拖拽画布设计对话流程，系统自动拨号、实时语音识别（ASR）、大模型生成回复、语音合成（TTS），通话全程录音并结构化分析。

**核心技术栈**：
- 后端：Java Spring Boot + Spring Cloud（多租户）+ MyBatis-Plus
- 通信：FreeSWITCH（Docker）+ ESL 事件监听
- AI：云 ASR/TTS API + DeepSeek/OpenAI LLM
- 存储：MySQL（业务）+ Redis（会话/缓存）+ ClickHouse（通话日志分析）
- 前端：Vue3 + TypeScript + **AntV X6**（对话流程图画布编排）
- 实时：SSE 推送通话状态/日志到前端

**覆盖 JD**：JD4（FreeSWITCH/SIP/外呼）、JD5（热线客服/AI外呼）、JD6（对话流程图/Prompt配置/通话日志分析/指标监控）、JD13（SSE/Redis Lua/幂等）

**工作量预估**：6-8 周

---

### B. SaaS 自动化工作流集成平台

**一句话定位**：可视化画布编排业务流程，多 Agent 协作执行，对接第三方系统与 IoT 设备。

**业务场景**：企业运营人员拖拽画布设计自动化流程（如：CRM 新客户→自动发邮件→调用 AI 生成跟进话术→写入看板），支持自然语言转流程，多 Agent 分工协作完成复杂任务。

**核心技术栈**：
- 后端：Java Spring Boot + RabbitMQ（任务队列）+ DAG 流程引擎
- Agent 编排：LangGraph + CrewAI（多 Agent 分工/协作）
- LLM：DeepSeek API + **模型路由/多模型成本管理**（JD29 加分项）
- 适配器：HTTP/API 适配器 + OCR 单据适配器 + MQTT 物联网设备适配器
- 存储：MySQL + Redis（分布式锁 Lua）+ Qdrant 向量库
- 前端：Vue3 + TypeScript + **AntV X6**（流程画布）+ Element Plus
- 实时：SSE 推送任务进度
- 企业能力：多租户/企业权限/共享额度/操作审计（JD29 加分项）

**覆盖 JD**：JD1（AI Agent/数据打通）、JD3（SaaS/Agent）、JD5方向④（Agent原型）、JD11（CrewAI/Agent观测）、JD12（MQTT/多源数据）、JD13（SSE/Redis Lua/幂等）、JD15（LangGraph/Dify）、JD20（Agent核心机制/多Agent协作/ReAct）、JD29（工作流画布/模型路由/企业权限）

**工作量预估**：8-10 周

### C. AI 应用评测与可观测平台

**一句话定位**：追踪 LLM 应用每次调用，Prompt 版本 A/B 对比，bad case 回归集，Agent 全链路监控。

**业务场景**：AI 应用开发团队在迭代 Prompt 和模型时，需要一个平台记录每次调用的输入/输出/延迟/成本，自动跑评测集对比版本优劣，标注 bad case 并回归，监控线上 Agent 的决策准确率。

**核心技术栈**：
- 后端：Python FastAPI（主）+ 少量 Go（性能热点）
- 数据采集：SDK 自动注入 LLM 调用链路追踪（支持 LangChain/LangGraph/CrewAI/Dify）
- 评测：自动化评测集执行 + 人工标注 bad case + 回归测试
- 存储：MySQL（元数据）+ ClickHouse（调用日志）+ Qdrant（语义检索相似 case）
- 前端：Vue3 + TypeScript + ECharts 看板 + Element Plus
- 监控：调用延迟/Token 消耗/成本/成功率/幻觉率看板
- 部署：Docker Compose（≤5 服务）

**覆盖 JD**：JD5方向③（prompt评测/日志/看板）、JD6（机器人指标监控）、JD11（Agent观测/度量/分析）、JD18（评测服务/算法工程化/性能优化）、JD20（Agent评估体系/自动化测试/LLM监控）、JD21（自动化测试/接口测试/测试报告）、JD15（FastAPI/向量库）

**工作量预估**：6-8 周

## 三、项目间分工与不重叠

| 维度 | A 外呼平台 | B 自动化工作流 | C AI 评测平台 |
|---|---|---|---|
| 核心域 | 语音通信 | 流程编排+Agent | LLM 可观测+评测 |
| 主语言 | Java | Java + Python Agent | Python FastAPI |
| 前端画布 | 对话流程 X6 | 工作流 X6 | 看板 ECharts |
| 特色技术 | FreeSWITCH/SIP/ASR/TTS | 多 Agent 协作/MQTT/模型路由 | 调用追踪/评测集/bad case 回归 |
| 存储特色 | ClickHouse 通话记录 | Redis Lua 锁/Qdrant | ClickHouse 调用日志 |
