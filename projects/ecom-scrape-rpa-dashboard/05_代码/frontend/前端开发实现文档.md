## 2. 接口对接（含 5A 未就绪的现实处理）

- `src/api/client.ts`：axios `baseURL='/api'`、`timeout=8000`；响应拦截 `code!==0` 抛 `ApiError(code,message,trace_id)`；**请求去重**：同参数 1s 内复用同一 Promise（内存 Map + 1s 过期）；`50301`/网络失败置全局 `apiState.unavailable` → 顶部条。
- `src/api/index.ts`：4 个 fetch 函数；**50301（含路由未实现）→ 本地 stub 兜底并置 `usingMock`**；其余错误码原样抛给视图走 error 态（不用 mock 掩盖真实错误）；对返回结构做校验（数组/series 字段），结构异常抛明确错误。
- `src/api/stub.ts`：**# MOCK:** 本地 stub，结构严格按架构 §5.4 样例 JSON（trend/compare/top-changes/health 四份），确定性生成（无随机数），未臆造字段。
- **筛选器 1s 防抖**：`src/composables/useViewData.ts` 统一三态（loading/empty/error）+ watch 防抖 1000ms + 过期响应丢弃（seq 号）。
- 筛选状态支持 URL query 直达（`#/trend?sku_id=..&days=30` 等），便于走查与分享。

### 5A 并行开发的实测状态（2026-11-23 17:30 前后实测，后端行为在演进）

## 3. 交互实现（三态 / 503 / 防抖 / 去重）

- **三态**：每个视图统一 loading（「加载中…」）/ empty（「当日无数据，请先跑采集」）/ error（「加载失败：{message}」+ 重试按钮）。
- **503 顶部条**：红条「数据接口暂不可用（后端 5A 未就绪或该路由未实现），最后更新 <时间>」+ 重试按钮（整页刷新，hash 路由回到原页签重新拉数）。
- **mock 环境标识（T32）**：黄条 + StatTile 指标 `# MOCK` 标注 + 页脚「当前为 mock 环境（本地 stub 数据）」文案三处齐全。
- 防抖/去重见上节；无表单无弹窗（本看板为只读筛选型工具）。

## 6. 契约复核清单（5A 落地 openapi.json 后，主 Agent/5.5 需处理）

1. **`/api/health` 语义冲突**：5A 当前返回 `{status,db,uptimeSec}`（服务健康检查），架构 §5.4 #4 定义的是采集健康度（success_rate/blocked_rate/p95/series）。两者同名不同义——建议 5A 将健康检查挪 `/api/ping` 或按 §5.4 实现 `/api/health`。
2. **响应字段命名**：5A 实测 `traceId`（驼峰），架构 §5.1 规定 `trace_id`（snake）；`cached` 字段 5A 未返回（§5.1 要求不省略字段）。
3. **过渡期规则移除**：`src/api/client.ts` 中「404+40401+Cannot GET 前缀 → 视为接口未实现走 stub」的规则在 5A 实现全部路由后应删除。
