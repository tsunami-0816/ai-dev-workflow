## 2. 任务拆解（按端到端链路，不按文件）

> 每条链路 = 一组任务，写清 起点 → 节点与落点文件 → 终点（用户可见结果）+ 验证动作。
> 风险级别按第 4 步固定清单判定：关键（鉴权/数据迁移/并发事务/外部 API 与密钥/部署启动脚本/公共组件签名/闸门脚本）、高（核心链路新增模块/跨端契约/批处理定时）、中（一般业务逻辑/内部接口）、低（样式/文案/工具函数）。

### L1 配置装载与任务编排（起点：运维改 YAML 或命令行触发）

| 任务 | 端到端闭环（输入 → 处理节点/落点 → 输出） | 优先级 | 风险 | 依赖 | 验收标准 / 验证动作 | 映射 |
|---|---|---|---|---|---|---|
| T01 配置装载与强校验 | `targets.yaml`+`sites.yaml`+`.env` → `config.py` 校验（平台枚举/rate.qps 区间/SKU 数）→ 计算 `config_hash` → 输出冻结的配置对象 | P0 | **关键**（口令/外部凭据装载） | — | 配置写错时进程退出码 2 且**不发起任何请求**；改 targets 后 `task.version` +1 | D-01~D-03 |
| T02 任务表与 CLI 骨架 | 命令行参数 → `task` upsert + `task_run(running)` → `cli initdb/collect/backfill` 执行 → 摘要 JSON | P0 | 高 | T01 | `cli initdb` 后 `SHOW TABLES`=14；`cli collect --platform jd` 有 ok 摘要 | D-04~D-08 |

**链路终点（用户可见）**：一条命令就能把库建好并跑一个平台，终端打印本次采集摘要。
**验证动作**：`py -3.11 -m app.cli initdb` → `py -3.11 -m app.cli collect --platform mock` → 退出码 0，`task_run` 新增一行 status≠failed。
**归属文件范围**：`05_代码/backend/app/config.py`、`app/cli.py`、`app/jobs/collect_job.py`、`config/**`、`sql/init/**`。

### L2 HTTP 采集主链路（起点：`collect` 触发一次请求）

| 任务 | 端到端闭环 | 优先级 | 风险 | 依赖 | 验收标准 / 验证动作 | 映射 |
|---|---|---|---|---|---|---|
| T03 反爬五件套 | domain → 令牌桶 acquire → UA/header 模板 → Cookie 池 → 代理池 → httpx 请求 → 输出响应 | P0 | **关键**（限速并发 + 外部站点凭据） | T01 | 并发 4 时同域相邻请求 `at` 差 ≥1500ms；Cookie 空池走 none 路径不报错 | D-09~D-13 |
| T04 观测与风控识别 | 响应 → 状态码 + 关键词/302 判定 → `blocked_flag` → 写 `antibot_metrics` → 输出可聚合指标 | P0 | 高 | T03 | mock 注入 429 → blocked 有记录；`/api/health` 三指标非空 | D-14、D-21 |
| T05 适配器基类与注册表 | platform → `registry` 取 adapter → `fetch_list/fetch_detail` → 8 字段统一结构 | P0 | 高（公共签名） | T01 | 新增 mock adapter 不改下游即可跑通 | D-15、D-22 |
| T06 四站点适配器 | (platform, keyword, page) → 列表/详情请求 + parsel 解析 → 8 字段 item 列表 | P0 | 高 | T05、T03 | 每个平台 ≥100 SKU 进 stg（mock 下可复现）；fixtures 单测通过 | D-16~D-19 |
| T07 原始快照 | 响应体 → `data/raw/<platform>/<date>/<url_hash>.html` → 表存指针 → 可离线重放解析 | P1 | 中 | T03 | 用快照文件离线解析得到与在线一致的 item | D-20 |

**链路终点**：一次 `collect` 在 DB 里留下 `antibot_metrics` 行 + `raw_page` 指针 + `stg_price_item` 原始行。
**验证动作**：`cli collect --platform mock` 后 `SELECT COUNT(*) FROM antibot_metrics WHERE at>=CURDATE()` >0，`stg_price_item` 行数 ≥100。
**归属文件范围**：`05_代码/backend/app/antibot/**`、`app/adapters/**`、`config/sites.yaml`、`data/raw/**`。

### L3 断点续采与去重（起点：一页解析完成 / 进程被 kill 后重启）

| 任务 | 端到端闭环 | 优先级 | 风险 | 依赖 | 验收标准 / 验证动作 | 映射 |
|---|---|---|---|---|---|---|
| T08 页级事务 + 逐 SKU 状态 | 一页 item → 单事务写（`stg_price_item` + `task_run_item` + `cursor`）→ 提交后游标前进 | P0 | **关键**（事务/幂等） | T02、T06 | 事务中途 kill → 重跑该页无重复无漏采；1 个坏 SKU 只 fail 该条 | D-23、D-24、D-27 |
| T09 续采与唯一键 | `interrupted` run → 读 cursor 从下一页继续 → item 计数自愈 → 唯一键兜底 | P0 | **关键**（幂等/数据一致性） | T08 | `cli resume --run-id` 后：并集=targets 全集，交集 ok=0 | D-25、D-26 |
| T10 暂存表与幂等写入 | 解析结果（原文+解析值双列）→ `stg_price_item` upsert(run_id,platform,sku_id) → 供 L5 取批 | P0 | **关键**（P0-01 修法，唯一缓冲） | T08 | 重跑同页 → stg 行数不增；脏值保留原文且 price=NULL | D-28 |

**链路终点**：中断-重启后数据不重不漏，`stg_price_item` 里能看到「面议」这类原文而价格表里没有脏行。
**验证动作**：采集中 `Ctrl+C` → `cli resume --run-id=<id>` → SQL 比对 `task_run_item` 与 targets（漏采 0、重复 0）。
**归属文件范围**：`05_代码/backend/app/jobs/collect_job.py`、`app/cli.py`、`app/db.py`、`sql/init/01_schema.sql`。

## 4. 开发规范

### 4.1 代码规范
- Python：`ruff`（line-length 100）+ `black` 风格；类型注解覆盖公共函数签名；禁止裸 `except:`；禁止用 `time.sleep` 等 DOM（用显式等待）。
- SQL：统一放 `sql/init/`（DDL）与 `sql/queries/`（查询），业务代码不内联长 SQL；写操作只走 rw 池，API 只走 ro 池。
- 前端：Vue 3 组合式 API + `<script setup lang="ts">`；指标计算一律在后端（前端只格式化），避免与 Excel 口径分叉。
- 配置：只走 `.env` / `config/*.yaml`；**禁止硬编码连接串、Cookie、口令**；`config/cookies/` 进 `.gitignore`。

### 4.2 命名规范
- 表/字段：snake_case（`price_snapshot`、`task_run_item`）；索引 `idx_`、唯一键 `uk_`、分区 `p_`。
- 接口：`/api/<资源>`，查询参数统一 snake（`sku_id`/`days`/`limit`）。
- 任务/运行：`task.name = daily_<platform>`；`run_id` 自增，`trace_id` 8 位十六进制。
- 前端组件：`CardBase.vue`/`StatTile.vue`/`DataTable.vue`；视图 `TrendView.vue` 等 PascalCase。

### 4.3 提交规范
- `feat(scope): 说明` / `fix(scope): 说明` / `docs` / `test` / `chore`；scope ∈ `collect|rpa|clean|db|report|api|web|ops`。
- 一次提交只做一条链路的一小步；**D-01～D-93 编号写进提交体**（如 `feat(clean): 唯一写入口 D-47`）。
- 关键风险任务（T01/T03/T08/T09/T10/T18/T19/T20/T28）提交前必须本地跑对应验证命令并把输出贴进提交体。

### 4.4 注释规范
- 「为什么」而非「做什么」：例如 `# 先落暂存再推游标：断电时宁重不漏（D-23）`。
- 每个降级/兜底分支必须有注释写触发条件与去向（如 `# 429 → 长冷却 30s，不走指数退避`）。
- 引用设计编号：`# 见架构 §4.5 Q2：取数窗口 +1 天`。

## 7. 异常分支

| 场景 | 前端表现 | 后端/任务表现 | 兜底与留证 |
|---|---|---|---|
| **网络失败**（DNS/连接拒绝/超时） | 顶部条「数据服务暂不可用，最后更新 <时间>」，可点重试；不白屏 | httpx 超时（connect 5s/read 10s）→ 指数退避 1s×2^n max 3 次 → 记 `antibot_metrics.http_status=0` + `retry_no` | 重试耗尽 → 该 SKU `fail` → run `partial`；日志含 url_hash |
| **数据为空**（当日无快照/查询无结果） | 空态文案「当日无数据，请先跑采集」，不显示 0 值图表 | 接口返回 `code=0, data=[]`（不是错误）；报表生成空态并标注 | `/api/trend` 无快照返回 `40401`；其余列表型返回空数组 |
| **重复提交**（采集重跑 / 报表重复生成 / 页面连点） | 按钮 1s 内请求去重；重复查询走缓存 `cached=true` | 页级事务 + `stg` 唯一键 `(run_id,platform,sku_id)` 幂等；已有 running run 拒绝并发；`report_file` 同日覆盖更新 | 唯一键 `uk_platform_sku_date` 二次兜底，禁止重复行 |
| **超时**（DB 连接/查询慢/接口 8s） | axios timeout=8000 → 统一 toast + 重试按钮 | DB 不可用 → 503 `50301`；查询 >3s 记慢查询日志；RPA 每步 15s 超时重试 2 次 | `wait-db` 重试 3 次；调度失败重试 1 次后写 `alerts.jsonl` |
| **配置错误**（YAML 非法/平台拼错/qps 越界） | —（进程未起，无页面） | 退出码 2 + 明确报错行号，**不发任何请求** | 配置校验单测覆盖 4 类非法输入 |
| **风控/封禁**（429/验证码/302 登录） | 健康度页封禁率上升 + 顶部「数据可能不完整」 | blocked_flag=1 + block_reason；长冷却 30s；换 UA→Cookie→代理→降并发→RPA 低频补采 | `raw_page` 保留风控页快照，可事后复核 |
| **清洗异常**（pandas 抛错/单行脏值） | 报表标注「清洗失败，数据未更新」 | 整批不写 `price_snapshot`（防半干净污染），`clean_report.status=failed` | 次日从 `stg` 重跑；单行异常记 `rule=unexpected` 并拦截 |
| **磁盘/写盘失败** | — | 报表 `status=failed` + 告警，不删旧报表；raw 落盘失败记 WARN 继续解析 | `prune` 保留策略 + 磁盘水位日志 |

## 8. 边界输入

| 类型 | 具体输入 | 期望行为 |
|---|---|---|
| **超长** | 商品标题 1000 字 / >255 字符 | 归一后 `len>255` 按 `rule=range` 拦截并记 `clean_issue`；报表列宽上限 + wrap，不撑爆 |
| **特殊字符** | emoji、全角空格、`'` `"` `;--`、`<script>`、SQL 注入串 `' OR 1=1--` | 全程参数化 SQL（禁拼接）；前端文本插值不 `v-html`；归一折叠不可见字符；注入串按普通文本入库不执行 |
| **并发** | 4 并发同域 / 同时起两个采集进程 / 页签连点筛选 | 令牌桶串行化保证 `MIN(diff)≥1500ms`；第二采集进程被文件锁拒绝（退出码 4）；前端 1s 去重 + 服务端 60s 缓存 |
| **数值边界** | price=0/0.01/99999/100000/NULL/负数；sales_num=0；days=1/7/30/90；limit=1/50/51 | 0.01–99999 通过，0 与 100000 拦截；NULL 走缺价策略；`days∉{7,30}` → 40001；`limit>50` → 40001 |
| **时间边界** | 跨月分区、跨年 02:00 定时、服务器时区非 +08:00 | 启动自动补下月分区；cron 固定 `Asia/Shanghai`；`captured_date` 统一按业务时区 |
| **文件/路径** | cookies 目录不存在、proxies.txt 为空、data 目录无写权限 | 均可降级：none 路径 / 直连 / WARN 继续（不 crash） |
