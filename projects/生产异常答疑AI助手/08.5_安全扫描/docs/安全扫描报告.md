## 三、安全扫描问题清单

### 已修复（P1）

| 编号 | 等级 | 漏洞 | 影响 | 复现 | 修复 | 验证 |
|---|---|---|---|---|---|---|
| SEC-01 | **P1** | 上传文件名路径穿越：`storage_path = join(UPLOAD_DIR, f"{doc.id}_{file.filename}")`，filename 含 `/` 时可逃逸 uploads 目录任意写文件（扩展名白名单限定 .pdf/.doc/.docx，需 admin 权限） | 越目录写文件 | `security_probe_traversal.py` 用 `x/../../path_traversal_probe.pdf` 实证写入 `data/` 成功 | `document_service.py` L49-51 加 `os.path.basename` 净化 | 复测：逃逸=False、落点=uploads 内 ✅；P0 回归 20/20 ✅ |

### P2 留档（下版本修复）

| 编号 | 等级 | 问题 | 分析与处理建议 |
|---|---|---|---|
| P2-01 | P2 | 种子账号弱密码（admin/admin123 等 5 个，init_db.py） | 本地验收环境保留以便测试；**部署/交付前必须改密**并从此文件移除默认值 |
| P2-02 | P2 | CORS `allow_origins=["*"]` 且 `allow_credentials=True` | 本地单机 127.0.0.1 影响有限；部署时改为前端具体来源 |
| P2-03 | P2 | python-jose 3.5.0 CVE-2024-33663（算法混淆，CVSS C:H/I:H） | **触发条件不适用**：本系统仅 HS256 对称密钥且 `jwt.decode` 钉死 `algorithms=["HS256"]`，漏洞需非对称公钥配置。若未来启用 RS256/EC 必须先换库（PyJWT）复评 |
| P2-04 | P2 | python-multipart 0.0.9 多个高危 DoS（CVE-2024-53981、CVE-2026-42561、CVE-2026-53539 等，CVSS A:H） | 唯一 multipart 入口 `/documents/upload` 需 admin 鉴权且体解析发生在鉴权后，触发需 admin token；本地单机影响面为管理员自身。建议下版本升级 python-multipart 至最新 |
| P2-05 | P2 | 登录接口无速率限制 | 本地单机影响有限；暴露到网络时需加限流/锁定 |
