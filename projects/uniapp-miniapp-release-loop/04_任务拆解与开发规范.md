## 5. 开发规范

- **代码**：TS `strict: true`、禁 `any`（确需时 `// eslint-disable` 注明原因）；Vue `setup` 语法 + `ref/reactive`；后端分层 `web/domain/infra/mq`，Controller 不写业务；统一 `Result<T>` 包装；单函数 ≤ 40 行、文件 ≤ 400 行；设计 token 只从 `design/tokens.ts`（hex/字号/圆角/间距）取值，页面内不写裸值。
- **命名**：文件 `kebab-case`（组件 `PascalCase.vue`）；Java 包 `com.uniapp.booking.*`；DB 表/字段 `snake_case`；Redis key `ub:<域>:<对象>[:<键>]`；错误码 `4xxxx/5xxxx` 五位，常量名 `CODE_DUPLICATED` 之类。
- **提交**：`<type>(<scope>): <subject>`（`feat/fix/refactor/test/docs/chore`，scope=`fe/be/cf/db/mq/ops/qa`），一任务一提交；body 写「验证命令 + 结果」。
- **注释**：公共函数必须有「入参/出参/异常」三行；魔法数字必须注明来源（指标编号或架构编号，如 `// C05 幂等 TTL 600s`）；禁 `// TODO 后续再说`（要留就写清责任与判据）。

## 7. 异常分支

| 场景 | 前端 | 后端 / 云函数 |
|---|---|---|
| 网络失败（断网、DNS 失败） | `request.ts` 捕获→「网络不稳定，请重试」+ 保留已填表单 | 云函数 1 次重试后返回 50001 |
| 请求超时（>3s） | toast「请求超时」+ 按钮恢复可用 | 云函数 abort + 后端请求超时 5s 兜底 |
| 数据为空（列表空/我的空/搜索无结果） | 空态文案 + 占位图形，不显示 0 条表格 | 后端返回 `data: []` 而非 null |
| 重复提交（连点/重复进页面） | 按钮 loading + 禁用（T-406） | 幂等返回首单 + `duplicated:true`（T-402），不再报错 |
| 消息投递/消费失败 | — | 重试 3 次 → 入 DLQ；`notify_log` 幂等不翻倍 |
| 用户中途退出/断网 | 表单草稿存本地（`uni.setStorage`），重进恢复 | 未提交不落库，无半单 |
| 登录态过期（JWT 2h） | 40103 → 跳登录页并提示「登录已过期」 | 黑名单校验 + 40103 |
| MQ / Redis 不可用 | 前端仍有明确提示 | 缓存 miss 直接回源；MQ 失败记 `error_log` 但预约本身成功（可用性优先） |

## 8. 边界输入

| 类型 | 处理 |
|---|---|
| 超长文本（备注 1000 字、地址 500 字） | 前端 `maxlength` 截断 + 后端 `@Size` 校验，超限→40001 并指明字段 |
| 特殊字符 / emoji / SQL 注入串（`' or 1=1`、`<script>`） | 参数化 SQL + 白名单校验（手机号 `^1\d{10}$`、日期 `YYYY-MM-DD` 且在 30 天内）；回显统一 HTML 转义 |
| 并发（同人同日同时段双击/两设备） | Redis 幂等键 + DB 唯一索引双保险，只留 1 条 |
| 超大 body（>2MB）/ 非 JSON Content-Type | 后端 413/400；网关层限 1MB |
| 非法日期（2099-01-01、过去的日期） | 40002，前端日期选择器限制范围 |
