## 三、② 依赖漏洞

### Python（测试依赖）

命令：`python -m pip_audit -r 08_测试/qa-automation/requirements.txt --format=json`（`docs/pip_audit.log`）。

- **1 个唯一 CVE / 2 条重复记录**：`pytest 8.3.3` → `PYSEC-2026-1845`（CVE-2025-71176，UNIX `/tmp/pytest-of-{user}` 本地 DoS/提权）。
- 影响面：仅测试机、Windows、非生产运行时 → **P3（F-04）**；修复版本 pytest 9.0.3，升级需回归 pytest 插件兼容性，留 v1.1。
- 其余依赖（allure-pytest、PyYAML、pluggy、attrs、colorama、iniconfig）0 漏洞。

### Node（前端）

命令：`npm audit --json --registry=https://registry.npmjs.org`（`docs/npm_audit.log`；官方 registry，避开 npmmirror 的 NOT_IMPLEMENTED）。

- 统计：**56 个漏洞 = 32 high / 14 moderate / 10 low / 0 critical**；328 prod + 302 dev + 51 optional。
- 性质：全部位于 **uni-app/Vite/Puppeteer 构建与测试链**（`vite`、`@dcloudio/*`、`puppeteer-core`、`adm-zip`、`postcss`、`ws`、`express` 等）。
- 运行时判断：
  - H5 交付物是静态 `dist/`，不运行 Node/Vite/Express；
  - 小程序交付物是编译后的 WXML/JS，不运行上述构建包；
  - 云函数（生产 Node 运行时）`package.json` 声明 **0 第三方依赖**（仅 Node 内置模块），`npm audit` 因无 lockfile 报 ENOLOCK；按声明即 0 依赖，无 CVE。
- 结论：不构成当前生产运行时 P0/P1；但公开部署前应升级 uni-app/Vite/Puppeteer → **P2（F-02）**。修复建议为 semver-major 升级，需单独回归构建与双端产物，不在 8.5 强行升级。

### Java（后端）

- 未覆盖：本机未安装 OWASP dependency-check / Maven 漏洞插件；`spring-boot 3.x`、`jjwt`、`mysql-connector-j` 版本来自 `pom.xml`，未做 CVE 库比对。
