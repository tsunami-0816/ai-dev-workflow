# 任务 Brief · 微信小程序头像（uniapp-miniapp-release-loop）

- 生产轨道：pure-image（单一图形标 / 小尺寸头像）
- 交付环境：默认 Canvas（workspace cws_62304426642379010）
- 任务 ID：avatar-20261118

## 1. 主题与用途

- 主题：微信小程序后台「填写小程序信息」页的头像位（144×144、PNG、≤2MB，端上以圆形裁切展示）。
- 核心对象：约拍 / 档期登记类工具型小程序的识别标记（无实体商品）。
- 用途：作为小程序头像在微信内展示；同一图兼作后续 H5 / 小程序内的品牌图形标。

## 2. 名称与文字边界（重要）

- 小程序名称仍在平台审核中，候选名为「约拍小助手demo」「小档期demo」「档期登记demo」，**未定稿**。
- 144×144 展示尺寸下中文名称不可读，且名称可能变更，因此本次按「无字图形标 / 小尺寸头像」制作，画面不出现任何文字；带字标的标准组合主版本待名称审核通过后再从本图派生。

## 3. 视觉意图

- 视觉命题：用「镜头光圈」把「约拍」翻译成一个 144px 仍能一眼认出的几何剪影，同时以等角排列的秩序感对应「档期/排期」。
- 构图：单一中心主体，环形围合；主体外接圆约占画幅 52%，四周均匀留白 ≥22%，避开四角（圆形裁切安全区）。
- 色彩职责：深墨绿 #123A34 承担底与负空间；纯白承担唯一图形色。两色，无第三色。
- 表现：平涂矢量感、边缘锐利、上下左右对称；无渐变、无光影、无投影、无立体、无描边、无颗粒、无装饰。

## 4. 尺寸与画幅

- 生成：1024×1024，1:1 正方形。
- 交付：另导出 144×144 PNG（微信后台要求），等比缩放不拉伸。

## 5. 禁止项

- 任何文字、字母、数字、商标、水印、边框、光晕、额外装饰。
- 通用图库图标式「相机 + 圆角矩形」贴图感；渐变与 3D 拟物。
- 复刻任何既有品牌 Logo。
