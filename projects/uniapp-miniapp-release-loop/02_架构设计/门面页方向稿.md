## 0. 一句话设计意图

把一个「预约拍写真」的动作，做成**一页可翻阅的档期账本**：深墨绿底像暗房，纸白字像相纸标签，1px 细线是装订线，编号是底片号——用户滑动时不是在刷电商卡片，而是在翻一本只有 4 个档期的册子。

## 1. 三个候选方向（遮住颜色仍可区分）

| | A 暗房档期（推荐） | B 样片接触印样 | C 票根档期 |
|---|---|---|---|
| 结构差异 | 单列账本：编号 + 细线分档，**无卡片容器** | 满版大图 + 极小字排版，图占 70%，文字贴边 | 票根化：虚齿线切分上下联，日期时段用等宽大数字 |
| 字体角色 | 中文衬线标题 + 无衬线正文 + 等宽数字 | 全无衬线，标题极小、图说话 | 中文粗黑 + 等宽数字主导 |
| 色彩体系 | 深底浅字（暗房） | 冷白底深字（印刷样张） | 暖米底 + 墨绿/朱红两色套印 |
| 隐喻 | 档期账本 / 底片编号 | 影棚接触印样 | 可撕票根 |
| 弱点 | 深底对低端机对比度需测（C10 要一起核对） | 首屏无价格与档期，转化弱 | 视觉重，4 个套餐易显碎 |

**推荐 A**：与已交付的小程序头像（深墨绿 `#123A34` + 白光圈）同族，进小程序后品牌连续；且「编号 + 细线」天然反 AI 模板（不依赖卡片海）。

## 2. 选定方向 A 的可执行要素

### 2.1 色彩（职责分明，不并列使用）

| 角色 | HEX | 用法 |
|---|---|---|
| 底（ground） | `#0E2B26` | 全页背景；照片以外的所有区域 |
| 主字 / 细线（paper） | `#F2EDE4` | 标题、正文、装订细线（细线用 12% 不透明度） |
| 次级信息（silver） | `#8E9A93` | 编号、说明、时间、单位 |
| 强调（stamp red） | `#C4453A` | **只用于状态标记**（「剩 2 档」「已约满」），单屏面积 ≤ 3% |
| 照片底（neutral） | `#1B3A33` | 图片占位 / 加载底色（避免白闪） |

禁止第三色以上；禁止任何渐变填充（含线性和径向）。

### 2.2 字体与字重

- 中文标题：思源宋体（Source Han Serif SC）**Semibold 600**，字号 34px / 行高 1.3 / 字距 +0.02em。
- 中文正文与标签：思源黑体（Source Han Sans SC）**Regular 400**，15px / 行高 1.7。
- 档期、价格、编号：等宽数字（IBM Plex Mono 500 或系统 `ui-monospace` 回退），**18px**，`font-variant-numeric: tabular-nums`。
- 字重只用 400 / 600 / 500(等宽)，**不引入第三种字重做层级**；层级靠字号与颜色差，不靠粗细堆叠。
- 中文页面禁用斜体；禁用字间距 ≥ 0.12em 的「伪高级」拉宽标题（除编号眉批可用 0.08em）。

### 2.3 圆角与间距

- 圆角：照片 `0px`；按钮 `2px`；标签 `2px`；**全页不出现 ≥ 4px 的圆角**。
- 间距基网 `8px`；常用档位 `8 / 16 / 24 / 40 / 64`。
- 页面左右安全边距 `24px`（375 基准）；区块之间 `64px`；清单行高 `72px`，行间**不用卡片间距**，用 1px 细线分隔。
- 触控目标 ≥ 44×44px（列表行整行可点）。

### 2.4 布局特征（375×812 基准）

```
┌ 24px 边距 ─────────────────────────────┐
│ ───────────── 装订细线 ──────────────  │  12%
│ No.01                    约拍   档期   │  ← 眉批：编号左，双词右侧留空
│                                        │
│ 城市轻写真         ┌──────────────┐   │
│ 周末 · 室内 2 套服装 │  样片 4:5     │   │  46%
│ ¥398              │  右侧出血      │   │
│                    └──────────────┘   │
│                                        │
│ 01 ───────────────────── 城市轻写真 ¥398 │  30%
│ 02 ───────────────────── 室内双人    ¥598│
│ 03 ───────────────────── 夜景外拍    ¥698│  ← 首行右侧朱红点 +「剩 2 档」
│                                        │
│ ──                                     │  12%
└────────────────────────────────────────┘
```

- 单列纵向，**无横向滑动**；照片只允许向右出血，不许左右对称居中。
- 套餐清单**没有卡片**：编号贴左、细线贯穿、名称居中偏左、价格贴右，四段对齐成固定栅格。
- 首屏不出现 tabBar 文案堆叠；tab 只在页面底部固定两条（首页 / 我的），图标用 1px 线描，不用 emoji。

### 2.5 动效（motion-web 口径，强度低）

- 只做两处：① 进入时细线从左到右「曝光」铺开（`transform: scaleX(0→1)`，`transform-origin: left`，480ms，`cubic-bezier(.2,.7,.3,1)`）；② 点清单行时价格数字 300ms 内做一次等宽数字跳动（`counter` 递增）。
- `prefers-reduced-motion: reduce` 时两处全部退化为直接呈现终态，不做位移与淡入。
- 禁止：整页 fade-up 串联、hover 抬升阴影、视差、粒子、噪点铺满。

### 2.6 明确「不做什么」

紫蓝渐变、发光/霓虹描边、玻璃拟态与模糊底、卡片套卡片、三等分特性卡、居中 Hero + 大标题渐变字、圆角 ≥16px 的白色卡片海、emoji 当图标、Badge 满屏、`transition: all`、无 `prefers-reduced-motion` 的入场动画、装饰用胶片噪点铺满全屏。
