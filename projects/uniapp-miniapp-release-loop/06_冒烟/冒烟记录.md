### 1.1 环境风险（已登记 Q-024，P2）

本机同时存在**两套 MySQL 同名库**：原生 `3307`（后端实际在用）与容器 `3308`（`rag-mysql`，另有一份旧的 `uniapp_booking`：3 用户/5 单/5 通知）。同理 `6379` 上还有容器 `rag-redis` 与原生 Redis 并存。

后果：`scripts/smoke_batch3.py` 原先把管理 SQL 写死 `--port=3308`，清理与断言都打到**错误的库**，导致 8 项**假失败**（`DB 计数=1`、`notify_log=10`、`A total=基线+11` 等）。
处理：脚本改为 `SMOKE_MYSQL_PORT` ＞ `MYSQL_PORT` ＞ `3308` 三级取值，本轮以 `MYSQL_PORT=3307` 复跑 → **全部通过**。7.5 数据重置前需固定端口口径（写进交付文档）。
