# 项目设计书 · SaaS 自动化工作流集成平台

## 1. 项目一句话
可视化画布编排业务流程，多 Agent 协作执行，对接第三方 API 与 IoT 设备，支持自然语言转流程和多模型路由成本管理。

## 2. 业务场景
企业运营/IT 团队需要打通多个 SaaS 系统（CRM/邮件/飞书/监控），但缺乏编程能力。本平台：
- 运营拖拽画布设计自动化流程（如：CRM 新线索→自动发邮件→AI 生成跟进话术→写入看板→通知销售）
- 支持多 Agent 分工：一个 Agent 做信息抽取，一个做决策，一个做执行
- 支持自然语言描述需求，LLM 自动生成流程草稿
- 对接 MQTT 物联网设备数据（如传感器触发告警→自动创建工单）
- 多租户企业级权限：团队空间、共享额度、操作审计

## 3. 技术栈

| 层 | 选型 | 说明 |
|---|---|---|
| 后端主语言 | Java 17 + Spring Boot 3 + Spring Cloud Alibaba | 流程引擎/租户管理/API 网关 |
| Agent 运行时 | Python FastAPI + LangGraph + CrewAI | 多 Agent 编排（任务规划-执行-记忆-工具调用） |
| LLM 网关 | 自研模型路由层 | DeepSeek/OpenAI/Claude 路由，按成本/延迟自动选择，Token 计量 |
| 流程引擎 | 自研 DAG 引擎（Java） | 节点编排/条件分支/循环/错误重试 |
| 消息队列 | RabbitMQ | 异步任务执行、事件驱动 |
| 业务库 | MySQL 8 | 租户/流程定义/执行记录/权限 |
| 缓存 | Redis 7（Lua 脚本） | 分布式锁防重复执行、流程状态缓存、幂等 |
| 向量库 | Qdrant | RAG：流程模板检索、历史相似执行记录 |
| IoT 接入 | MQTT Broker（EMQX Docker） | 设备数据上报触发流程 |
| 前端 | Vue3 + TypeScript + Vite + Element Plus + **AntV X6** | 工作流画布编排 |
| 实时推送 | SSE | 流程执行进度实时推送 |
| 部署 | Docker Compose（≤5 服务） | backend-java + agent-python + MySQL + Redis + RabbitMQ |

## 4. 核心模块（P0）
1. **多租户与企业权限**：团队空间/角色权限/共享额度/操作审计日志
2. **工作流画布**：X6 拖拽节点（API调用/条件分支/Agent任务/代码块/MQTT触发/延时）
3. **DAG 流程引擎**：节点拓扑排序执行、失败重试/回退、SSE 进度推送
4. **多 Agent 编排**：CrewAI 多 Agent 分工（规划者/执行者/审核者），ReAct 推理
5. **模型路由层**：多 LLM 统一接口，按任务类型路由，Token 成本统计
6. **连接器市场**：HTTP API 连接器 + MQTT IoT 连接器 + OCR 文档连接器
7. **自然语言转流程**：输入"新客户进来自动发欢迎邮件"→LLM 生成流程草稿

## 5. 量化基线指标
- 画布支持 ≥ 30 节点复杂 DAG 流程
- 单流程并发执行 ≥ 100 实例
- API 节点调用成功率 ≥ 99%，失败自动重试 3 次
- 模型路由层支持 ≥ 3 个 LLM 提供商统一接口
- 自然语言转流程准确率（人工评审）≥ 70%
- MQTT 设备消息端到端触发延迟 ≤ 3s
