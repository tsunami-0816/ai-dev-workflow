# 项目设计书 · sd-image-workflow（Stable Diffusion 图像生成工作流）

> 目的：补 JD 缺口——证明"会搭 Stable Diffusion 本地推理 + ComfyUI 节点工作流 + API 批量出图"，对口思元环保/丰度科技。
> 硬件约束：RTX 2050 4GB 显存 → SD1.5 模型 + --medvram，不跑 SDXL。

## 1. 项目一句话
本地部署 Stable Diffusion WebUI + ComfyUI，搭一个"prompt → 文生图 → ControlNet Canny 构图控制 → 高清放大"的节点工作流，写 FastAPI 接口批量调用 SD API 生成电商产品图，批量出图后按命名规则归档成图册。

## 2. MVP 最小可用场景（必须能做完）
本地启动 SD WebUI（--medvram 模式，SD1.5 模型）→ ComfyUI 搭好文生图+ControlNet 节点流 → FastAPI 接口 POST /generate 接收 prompt 列表 → 批量调用 SD API 出 10 张电商产品图 → 用 ControlNet Canny 控制线稿构图 → 高清放大后按命名规则归档到 output/ 目录 → 整理成一个 HTML 图册预览。

**做完这件事，项目就算成了。** 不做视频生成（Runway/可灵）、不做 LoRA 训练、不做云端 SD API（只用本地）、不做前端画布、不做图床。

## 3. 技术栈

| 层 | 选型 | 说明 |
|---|---|---|
| SD 推理 | **Stable Diffusion WebUI（Automatic1111）** | SD1.5 模型，--medvram 4GB 显存模式 |
| 节点工作流 | **ComfyUI** | 节点式搭文生图 + ControlNet + 放大流程 |
| ControlNet | **Canny 模型** | 线稿构图控制 |
| API 封装 | **FastAPI** | POST /generate 批量生成接口 |
| Python | 3.10+ | 批量出图脚本 + FastAPI |
| 归档 | 本地文件系统 + HTML 图册 | 按命名规则存图，生成预览页 |
| 部署 | 本地直接跑（不做 Docker，SD WebUI 装驱动麻烦） | |

**明确不做**：SDXL（4GB跑不动）、视频生成（Runway/可灵是调云API，不算本地项目）、LoRA 训练、云端 SD API、前端可视化画布、图床/CDN。

## 4. 核心模块（P0，只做这些）

### 模块1：本地 SD WebUI 部署（0.5d）
- 装 Stable Diffusion WebUI（Automatic1111）
- 下载 SD1.5 基础模型（v1-5-pruned-emaonly.safetensors，约 4GB）
- 启动参数 --medvram --xformers，4GB 显存跑通文生图
- 确认 WebUI API 模式可用（--api 参数启动）

### 模块2：ComfyUI 节点工作流（1d，**核心**）
- 装 ComfyUI，下载同一份 SD1.5 模型
- 搭节点流：Load Checkpoint → CLIP Text Encode (prompt) → Empty Latent → KSampler → VAE Decode → Save Image
- 加 ControlNet：Load ControlNet Model (canny) → Apply ControlNet → 接收线稿图作为构图输入
- 加高清放大：Upscale Latent 节点，2x 放大后二次采样
- 导出工作流 JSON，可通过 API 调用

### 模块3：FastAPI 批量生成接口（1d）
- POST /generate：入参 {prompts: string[], negative_prompt: string, batch_size: int}
- 内部调用 SD WebUI API（或 ComfyUI API）批量出图
- 每张图按命名规则归档：output/{prompt前5词}_{timestamp}.png
- GET /gallery：返回 output/ 目录下所有图片列表
- GET /gallery.html：返回 HTML 图册页面（缩略图网格）

### 模块4：ControlNet 实操与批量出图（0.5d）
- 准备 5 张电商产品线稿图（手绘或从图截 Canny 边缘）
- 写 10 组电商产品 prompt（如"product photo of wireless earbuds on white background, studio lighting, 8k"）
- 批量跑：每组 prompt + Canny 线稿 → 出 5 张图 → 共 50 张
- 选最好的 10 张放进 final/ 目录

### 模块5：README 与交付（0.5d）
- README：怎么装 SD WebUI、怎么下模型、怎么启动 API、怎么跑批量脚本
- 贴 5 张最终效果图
- 写一份《工作流说明.md》：ComfyUI 节点流截图 + 每个节点作用

## 6. 数据模型
- 无数据库，纯文件系统
- output/ 目录：按 {prompt}_{timestamp}.png 命名
- final/ 目录：精选 10 张图
- ComfyUI 工作流 JSON：workflow.json 存档
