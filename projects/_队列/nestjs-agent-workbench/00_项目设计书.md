# 项目设计书 · NestJS Agent Workbench（Node.js AI对话工作台）

> 目的：补 JD 缺口——证明"能用 Node.js/NestJS 写后端"，对口垦驱智能 Agent 岗。
> MVP 原则：不做大规模系统，重点是把 NestJS 工程结构、TypeScript 类型、WebSocket、JWT/RBAC 做扎实。

## 1. 项目一句话
用户在 Vue3 前端登录后，创建对话窗口，通过 WebSocket 和后端建立长连接，后端调大模型 API 流式返回回答，对话历史存 MySQL。

## 2. MVP 最小可用场景（必须能做完）
用户注册/登录 → 创建新对话 → 在输入框发消息 → WebSocket 推送到后端 → 后端调 DeepSeek API → 流式返回 → 前端逐字显示回答 → 对话历史自动存库 → 刷新页面能看到历史记录。

**做完这件事，项目就算成了。** 不做多租户、不做RAG、不做Agent编排、不做微前端。

## 3. 技术栈

| 层 | 选型 | 说明 |
|---|---|---|
| 后端 | **Node.js 20 + NestJS + TypeScript** | Controller/Service/Module 标准 NestJS 结构 |
| 前端 | Vue3 + TypeScript + Element Plus | 登录页 + 对话列表 + 聊天窗口 |
| 数据库 | MySQL 8 | users / conversations / messages 三张表 |
| 缓存 | Redis | 登录 token 黑名单 + 对话会话缓存 |
| 实时通讯 | **WebSocket（ws/socket.io）** | 对话流式推送 |
| 大模型 | DeepSeek API（HTTP 调用） | 真调，不 Mock |
| 部署 | Docker Compose | 一键起 MySQL + Redis + 后端 + 前端 |

**明确不做**：微前端(qiankun/wujie)、RAG知识库、Agent编排、多租户、支付、权限细粒度到按钮级。

## 4. 核心模块（P0，只做这些）

1. **NestJS 工程骨架**：Module/Controller/Service/Repository 分层，TypeORM 操作 MySQL，DTO 校验（class-validator），全局异常过滤器。
2. **认证授权**：用户注册/登录，JWT 签发，守卫（Guard）做登录校验，简单角色区分（user/admin）。
3. **对话 CRUD**：会话列表、创建对话、消息历史分页查询。
4. **WebSocket 网关**：建立连接后认证 JWT，客户端发消息，后端调 DeepSeek 流式返回，通过 WebSocket 逐 chunk 推给前端。
5. **Redis 缓存**：热对话列表缓存，用户登出时 token 加黑名单。
6. **Docker Compose 部署**：backend/frontend/mysql/redis 四容器一键起。

## 5. 量化基线指标

| 编号 | 指标 | 验证方式 |
|---|---|---|
| M1 | NestJS 后端有 ≥5 个 Module（auth/conversation/message/chat/health） | step6 冒烟看目录结构 |
| M2 | 注册/登录/JWT 鉴权全链路通 | step6 手动注册→登录→带 token 访问 |
| M3 | WebSocket 能建立连接并收到大模型流式回复 | step6 发消息看逐字输出 |
| M4 | 对话历史存 MySQL，刷新页面能看到 | step7 查 DB + 前端刷新验证 |
| M5 | Redis 缓存生效（登出后 token 失效） | step6 登出后带旧 token 访问被拒 |
| M6 | Docker Compose 一键起全栈 | step6 docker compose up 后全服务通 |

## 6. 数据模型

- `users`：id, username, password_hash, role(user/admin), created_at
- `conversations`：id, user_id, title, created_at
- `messages`：id, conversation_id, role(user/assistant), content, created_at

## 7. JD 技能点覆盖（垦驱智能缺口）

| JD 技能点 | 落在哪个模块 |
|---|---|
| **NestJS / Node.js 精通** | 整个后端就是 NestJS 写的，标准 Module/Service/Guard 结构 |
| TypeScript | 后端 + 前端全 TS，DTO 带类型 |
| WebSocket 实时通讯 | 模块4 WebSocket 网关 |
| JWT / RBAC | 模块2 认证授权 |
| MySQL / Redis | 模块3 + 模块5 |
| Docker 部署 | 模块6 |
| 大模型 API 对接 | 模块4 调 DeepSeek |
