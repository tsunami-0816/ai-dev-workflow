# 项目设计书 · 智能外呼语音对话平台

## 1. 项目一句话
基于 FreeSWITCH + LLM 的 AI 外呼机器人平台，运营人员通过可视化画布设计对话流程，系统自动拨号、实时 ASR 转写、大模型生成回复、TTS 合成语音，通话全程结构化分析。

## 2. 业务场景
企业客服/营销团队需要批量外呼（通知、回访、满意度调查）。传统方式：人工拨号+话术脚本。本平台：
- 运营在画布上拖拽节点设计对话流程（开场→提问→分支→收集信息→结束）
- 配置号码池、拨打时间段、并发数
- 系统自动外呼，实时语音识别→LLM 决策→TTS 播报
- 通话结束后自动生成结构化摘要、意向标签、通话录音回放
- 看板展示接通率、平均通话时长、意向客户数、转人工率

## 3. 技术栈

| 层 | 选型 | 说明 |
|---|---|---|
| 后端主语言 | Java 17 + Spring Boot 3 + Spring Cloud | 微服务：呼叫调度/对话引擎/租户管理/分析看板 |
| 通信层 | FreeSWITCH 1.10（Docker）+ ESL | 通过 ESL 事件监听接听/挂断/DTMF |
| ASR/TTS | 云 API（阿里云/讯飞） | 流式 ASR + 实时 TTS，不本地部署 |
| LLM | DeepSeek API | 对话决策，function calling 收集槽位 |
| 消息队列 | RabbitMQ | 通话事件异步处理（录音上传/摘要生成） |
| 业务库 | MySQL 8 | 租户/流程/号码池/任务 |
| 缓存 | Redis 7（含 Lua 脚本） | 会话状态、分布式锁防重复拨打、幂等 |
| 分析库 | ClickHouse | 通话明细/指标聚合（接通率/时长/意向分布） |
| 前端 | Vue3 + TypeScript + Vite + Ant Design Vue + **AntV X6** | 对话流程画布编排 |
| 实时推送 | SSE（Server-Sent Events） | 通话进度/日志实时推送到运营看板 |
| 部署 | Docker Compose（≤5 服务） | FreeSWITCH + MySQL + Redis + ClickHouse + backend |

## 4. 核心模块（P0）
1. **租户与号码池管理**：多租户隔离，号码池配置，并发拨打上限
2. **对话流程画布**：X6 拖拽节点（开场/提问/分支/API调用/结束），导出 JSON 流程定义
3. **呼叫调度引擎**：读取流程定义→创建呼叫任务→FreeSWITCH 拨号→ESL 事件驱动对话
4. **实时对话循环**：ASR 流式转写→LLM 决策（含槽位收集/条件分支）→TTS 播报→SSE 推送前端
5. **通话后处理**：录音转写文本→LLM 生成摘要+意向标签→写入 ClickHouse
6. **运营看板**：接通率/通话时长/意向分布/实时通话监控（SSE）

## 5. 量化基线指标
- 单实例支持并发通话 ≥ 50 路
- ASR→LLM→TTS 端到端延迟 ≤ 2s
- 对话流程画布支持 ≥ 20 节点复杂流程
- 通话后摘要生成 ≤ 5s
- 看板查询最近 1 万条通话记录聚合 ≤ 500ms
